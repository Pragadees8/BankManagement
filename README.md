# BankManagement

## Overview

A simple console-based banking system built using Java. This application allows users to perform basic banking operations such as:

* Checking account balance
* Depositing money
* Withdrawing funds
* Viewing transaction history

## Features

* *Account Balance Inquiry:* Allows users to check their current account balance.
* *Deposit and Withdrawal Functionality with Validation:* Ensures that deposits and withdrawals are processed correctly, with checks for sufficient funds and valid amounts.
* *Transaction History Tracking:* Maintains a record of all transactions performed by the user.
* *Interactive Menu-Driven Interface:* Provides an easy-to-use command-line interface for interacting with the banking system.

## Technologies Used

* *Programming Language:* Java
* *Concepts:* Object-Oriented Programming (OOP), User Input Handling
* *Tools:* Eclipse
